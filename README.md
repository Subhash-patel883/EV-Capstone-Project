Electric Vehicle (EV) Capstone Project

Project Overview

This project analyzes Electric Vehicle (EV) data using Tableau.

Objectives

- Explore the available EV dataset.
- Compare vehicle categories and manufacturers.
- Visualize patterns and trends in the data.
- Present findings through Tableau dashboards and stories.

Tools Used

- Tableau
- GitHub

Project Files

- Tableau packaged workbook (".twbx")
- Dashboard and visualization screenshots

Conclusion

This project demonstrates how data visualization can help explore and understand electric vehicle data.
